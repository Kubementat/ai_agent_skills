---
description: 3 times Review, Improvement Implementation Loop for uncommited changes
---

Perform the following loop 3 times:          
- start a reviewer subagent to review the current uncommited changes in detail and print a list of the top 5 recommended improvements/fixes/changes        
- then start a worker subagent for implementing the recommended changes
          
Once all loops have finished: print all the performed changes as a list to review for the user including a list of all files touched
